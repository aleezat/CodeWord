# CodeWord

A Python-based Wordle-style guessing game using programming-related words.

## How to Play

- The game randomly chooses a programming-related word.
- You have **7 attempts** to guess the word.
- Each guess must be **5 letters**.
- Letter feedback is shown using:
  - 🟩 Correct letter and position
  - 🟨 Correct letter, wrong position
  - ⬜ Letter not in the word

## Features

- Random word selection
- 7 guesses per game
- Input validation
- Case-insensitive guesses
- Wordle-style letter feedback
- Programming-related vocabulary
